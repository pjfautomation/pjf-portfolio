# Landing page image assets

Generated with the built-in imagegen tool for fictional portfolio brands. Source generations remain in the user's Codex generated-images directory; these workspace copies are the shipped page assets. These are illustrative photographs, not evidence of real customers, credentials or products.

- `relay-workshop.png`: editorial photo of three professionals mapping an inquiry journey in a naturally lit studio.
- `coach-portrait.png`: fictional coach in plum knitwear, seated with a notebook in a warm studio.
- `clean-home.png`: clean lived-in apartment, cream sofa and blue cushions, with open space on the left.
- `daypack-graphite.png`: graphite 22 L backpack, warm studio lighting and bone background.
- `daypack-sand.png`: reference-based edit changing only the graphite bag fabric to Sand while preserving shape, pockets, straps and lighting.
- `daypack-detail.png`: reference-based product interior showing laptop compartment and notebook.

Local Manrope 400, 600 and 800 WOFF2 files come from the existing installed @fontsource/manrope package (SIL Open Font License).

Regenerate barrel/home previews using `node scripts/make-landing-thumbs.mjs`; those screenshots are derived from the working HTML, not imagegen mockups.
